# GitHub Upload Guide

This repository is ready to publish as **Prototype v0.1**.

## Recommended repository settings

**Repository name**

`living-role-memory`

**Description**

`An experimental AI-native approach to organisational knowledge transfer.`

**Suggested topics**

`ai` · `knowledge-management` · `knowledge-transfer` · `prototype` · `human-ai-interaction` · `organisational-memory`

## Upload

1. Create a new public GitHub repository named `living-role-memory`.
2. Do not initialise it with a separate README if you are uploading this package as-is.
3. Upload **the contents of this folder**, not the folder itself, so `README.md` and `index.html` sit at the repository root.
4. Commit the files to the default branch.

## Optional: publish the runnable prototype with GitHub Pages

Because the app is static, it can be served directly from the repository root.

In the repository settings, enable GitHub Pages for the branch containing the prototype and select the root directory as the publishing source.

The repository itself is complete without Pages; Pages simply provides a browser-accessible demo URL.

## Before sharing publicly

Check that the repository landing page shows:

- the Living Role Memory README;
- the explicit Prototype v0.1 status;
- the Try it instructions;
- the current-capability vs future-hypothesis boundary;
- the `docs`, `prompts-or-skill`, `examples`, and `evaluation` folders.

No API keys, credentials, enterprise data, or private user data are included in this package.
